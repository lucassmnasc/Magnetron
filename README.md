Correio espacial

**Magnetron** é um jogo de corrida espacial desenvolvido em linguagem **C** para a disciplina de **Programação Imperativa Funcional (PIF)** da **CESAR School**.

## 🚀 Sobre o Jogo

Em **Magnetron**, o jogador comanda uma nave espacial em pistas futuristas. Utilizando mecânicas em 2D, é inspirado em jogos clássicos de corrida, onde ganhar impulsos de velocidade e desviar dos obstáculos ao longo do percurso são essenciais para obter a vitória.

## 🛠️ Tecnologias e Requisitos

* **Linguagem:** C
* **Contexto:** Projeto acadêmico (CESAR School — Cadeira de PIF)
